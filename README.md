# TopList

A small React app for creating and managing “top lists” (e.g., favorite movies, books, restaurants, etc.).  
Built to practice modern React patterns, predictable state management with Redux Toolkit, and form handling with React Hook Form.

🌐 **Live demo:** https://neda-jahadi.github.io/topList

---

## Tech Stack

- **React 18**
- **Redux Toolkit** + **React Redux**
- **React Hook Form**
- **Create React App (react-scripts)**
- **Testing Library** (Jest DOM / user-event)
- **GitHub Pages** deployment

---

## Features

- Create a new list and add items to it
- Update / remove items
- Basic validation for form inputs (React Hook Form)
- Global state management using Redux Toolkit (slices, reducers, actions)
- Responsive, simple UI (focus on functionality and structure)

> Note: This is a learning/portfolio project. The focus is on clean structure and React patterns rather than a polished UI.
